Week 1 · Days 3–4

Branches, PRs & Pages

Work on dev, merge into main with a pull request, and put main online with GitHub Pages.

dev → PR → main → Pages

What a branch is

A branch is a separate line of commits. main holds the finished version. dev is where you try things. When dev is ready, a pull request copies its commits into main.

CommandWhat it does
git branchList branches; * marks yours
git switch -c devMake dev and move to it
git switch mainMove back to main

Make dev and push it Day 3

git switch -c dev
# ...edit, then ACP...
git add .
git commit -m "Add about section"
git push -u origin dev

The first push of a new branch needs -u origin dev. After that, git push is enough.

Open a pull request Day 4

  1. On GitHub, open your repo and click Pull requests, then New pull request.
  2. Set base: main and compare: dev.
  3. Check the list of changes, then click Create pull request.
  4. Give it a title and a sentence about what changed.
  5. Click Merge pull request, then Confirm merge.

GitHub often shows a yellow "dev had recent pushes" banner. Its Compare & pull request button is a shortcut to step 3.

After the merge

The merge happened on GitHub, so your computer's main is behind. Bring it up to date:

git switch main
git pull
git log --oneline   # the dev commits are here now
git switch dev      # back to work

Turn on GitHub Pages

  1. Repo Settings → Pages.
  2. Source: Deploy from a branch.
  3. Branch: main, folder: / (root). Click Save.
  4. Wait 1–2 minutes. The Actions tab shows progress.

Your site's address:

https://USERNAME.github.io/REPO-NAME/

Reading a merge conflict

This happens when two branches change the same line. Git marks both versions in the file:

<<<<<<< HEAD
<h1>Garden Club</h1>
=======
<h1>Community Garden Club</h1>
>>>>>>> dev

Keep the line you want, delete all three marker lines, save, then add and commit.

Common mix-ups

PR says "nothing to compare"

Your dev commits aren't on GitHub yet. Run git push while on dev.

Committed on main by accident

Run git status before every commit. It shows your branch on the first line.

Pages shows 404

The home page must be named index.html (all lowercase) and be in the top folder, not a subfolder.

Pages shows the old version

Did the PR merge? Then wait a minute and hard reload with Ctrl + Shift + R.
