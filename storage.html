localStorage & App State

Remember a user's choices after they reload the page, and keep what's on screen in step with your data.

setItem(key, string)getItem(key)removeItem(key)

The four methods

localStorage.setItem("theme", "dark");
localStorage.getItem("theme");    // "dark"
localStorage.getItem("nope");     // null
localStorage.removeItem("theme");
localStorage.clear();             // everything for this site

It only stores strings, and only in this browser on this computer.

Save an array or object

const favorites = ["Tomato", "Basil"];

// save: turn it into a string
localStorage.setItem("favorites", JSON.stringify(favorites));

// load: turn it back, with a default
const saved = JSON.parse(localStorage.getItem("favorites")) ?? [];

JSON.parse(null) gives null, so ?? [] starts you with an empty list the first time.

Load safely

If the saved text gets corrupted, JSON.parse throws. Wrap it:

function load(key, fallback) {
  try {
    return JSON.parse(localStorage.getItem(key)) ?? fallback;
  } catch {
    return fallback;
  }
}

function save(key, value) {
  localStorage.setItem(key, JSON.stringify(value));
}

One source of truth

Keep your data in one variable. When it changes: save, then re-draw.

let favorites = load("favorites", []);
render();

function addFavorite(name) {
  favorites.push(name);
  save("favorites", favorites);
  render();
}

function render() {
  list.replaceChildren();
  favorites.forEach((name) => {
    const li = document.createElement("li");
    li.textContent = name;
    list.append(li);
  });
}

Remember the last search Day 1

input.value = localStorage.getItem("lastSearch") ?? "";

form.addEventListener("submit", (e) => {
  e.preventDefault();
  const q = input.value.trim();
  if (!q) return;
  localStorage.setItem("lastSearch", q);
  search(q);
});

See it in DevTools

F12 → Application tab → Local storage → your site. You can view, edit and delete keys there. Clear them to test what a first-time visitor sees.

Common mix-ups

Saved value is [object Object]

You saved an object directly. Use JSON.stringify first.

.push is not a function

You loaded a string. Wrap the load in JSON.parse.

Saved, but the page didn't change

Call render() after you save.

Works for you but not the grader

Their storage is empty. Make sure the page works with nothing saved.
