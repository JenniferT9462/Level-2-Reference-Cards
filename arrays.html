Arrays & Data

Loop over a list, reshape it, filter it, and boil it down to one number. Every example uses this array:

The sample data

const plants = [
  { name: "Tomato", days: 70, sun: true },
  { name: "Lettuce", days: 45, sun: false },
  { name: "Pepper", days: 80, sun: true },
];

This is the same shape most APIs send back: an array of objects.

Basics

plants.length        // 3
plants[0]            // the Tomato object
plants[0].name       // "Tomato"
plants.at(-1)        // the last item
plants.push(newOne)  // add to the end

Indexes start at 0, so the last index is length - 1.

Loop: for…of and forEach

Use these to do something with each item, like put it on the page.

for (const plant of plants) {
  console.log(plant.name);
}

plants.forEach((plant, i) => {
  console.log(i, plant.name);
});

forEach returns nothing, so don't save its result in a variable.

map: reshape every item

Gives back a new array, the same length.

const names = plants.map((p) => p.name);
// ["Tomato", "Lettuce", "Pepper"]

const labels = plants.map((p) => `${p.name} (${p.days}d)`);

filter: keep some

Gives back a new, shorter (or equal) array. Return true to keep an item.

const sunny = plants.filter((p) => p.sun);
const quick = plants.filter((p) => p.days < 60);

find and some

plants.find((p) => p.name === "Pepper");
// the first match, or undefined

plants.some((p) => p.days > 75);  // true
plants.every((p) => p.sun);       // false

reduce: boil down to one value Week 6

const totalDays = plants.reduce(
  (sum, p) => sum + p.days,
  0           // starting value
);
// 195

const average = totalDays / plants.length;

Always pass a starting value. Without one, an empty array throws an error.

Chain them

Read it top to bottom: keep, reshape, then use.

const sunnyNames = plants
  .filter((p) => p.sun)
  .map((p) => p.name);
// ["Tomato", "Pepper"]

Sort a copy

const byDays = [...plants].sort((a, b) => a.days - b.days);
const byName = [...plants].sort((a, b) =>
  a.name.localeCompare(b.name)
);

sort changes the original array. Copy it with [...plants] first.

Common mix-ups

map gives [undefined, undefined]

With curly braces you need return: (p) => { return p.name; }

Changed the API data by accident

map and filter make copies. sort and push change the original.

plants.name is undefined

The array has no name. Its items do: plants[0].name.

reduce returns "07045…"

The numbers are strings. Use Number(p.days) inside the callback.
