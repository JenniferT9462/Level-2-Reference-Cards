Box Model & Flexbox

Every element is a box. Flexbox lines boxes up in a row or a column, with space between them.

margin › border › padding › contentdisplay: flex

The box model

margin: space outside
border
padding: space inside
content (width × height)

Add this to the top of every stylesheet, so width includes padding and border:

*, *::before, *::after {
  box-sizing: border-box;
}

Margin or padding?

  • Padding is inside the border. The background color fills it. Use it to give text breathing room inside a button or card.
  • Margin is outside the border and is always see-through. Use it to push boxes apart.
padding: 16px;            /* all sides */
padding: 8px 16px;        /* top+bottom, left+right */
margin: 0 auto;           /* center a box with a width */

Block or inline?

displayBehaves like
blockStarts a new line and is full width. div, p, h1, section
inlineStays in the line of text, and width is ignored. a, span, strong
inline-blockStays in the line, but takes width, height and padding

Flex container

These go on the parent. They arrange its direct children.

.row {
  display: flex;
  flex-direction: row;       /* or column */
  justify-content: space-between;  /* main axis */
  align-items: center;       /* cross axis */
  gap: 16px;                 /* space between items */
  flex-wrap: wrap;           /* go to next line if needed */
}

justify-content values

flex-startAll at the start (default)
centerGrouped in the middle
flex-endAll at the end
space-betweenFirst and last at the edges
space-aroundEqual space around each item

With flex-direction: column, the axes swap: justify-content works top to bottom.

Flex items

These go on a child.

.main-col { flex: 1; }      /* take the leftover space */
.sidebar  { flex: 0 0 240px; } /* stay 240px */
.logo     { margin-right: auto; } /* push the rest right */

Recipe: a nav bar

.site-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 12px 24px;
}
.site-header nav ul {
  display: flex;
  gap: 20px;
  list-style: none;
  margin: 0;
  padding: 0;
}

Recipe: a hero with an overlay Day 4

A see-through dark layer over the photo keeps white text readable.

.hero {
  min-height: 60vh;
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  color: white;
  background:
    linear-gradient(rgba(0, 0, 0, 0.55), rgba(0, 0, 0, 0.55)),
    url("images/garden.jpg") center / cover;
}

In rgba(0, 0, 0, 0.55), the last number is opacity: 0 is clear and 1 is solid.

Buttons people can use

.cta {
  display: inline-block;
  padding: 12px 24px;
  background: #1d5c3f;
  color: white;
  border-radius: 8px;
  text-decoration: none;
}
.cta:hover { background: #164a32; }
.cta:focus-visible {
  outline: 3px solid #f2b705;
  outline-offset: 3px;
}

Never set outline: none without adding a focus style back. Keyboard users need to see where they are.

Contrast

Text needs enough contrast with what's behind it:

  • 4.5 : 1 for normal text
  • 3 : 1 for large text (about 24px, or 19px bold)

Check your colors with the WebAIM Contrast Checker or the color picker in DevTools.

Common mix-ups

Flex properties do nothing

display: flex goes on the parent, not on the items you want to move.

Box is wider than the screen

width: 100% plus padding overflows. Add box-sizing: border-box.

width on a link is ignored

Links are inline. Use display: inline-block.

Vertical centering doesn't work

The container needs a height (like min-height) for there to be space to center in.
