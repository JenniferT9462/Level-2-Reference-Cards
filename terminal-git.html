Terminal & Git

Move around your computer by typing, then save snapshots of your work and send them to GitHub.

git add .git commit -m "…"git push

Where am I?

Use Git Bash on Windows or Terminal on a Mac. Check where you are before you run anything else.

Set up Git once Day 1

Git puts this name and email on every commit you make. Use the email from your GitHub account.

git --version
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main

# check what you set
git config --global --list

The ACP loop

Add, commit, push. You'll do this many times a day.

  1. Add picks which changes go in the next snapshot (staging).
  2. Commit saves the snapshot on your computer with a message.
  3. Push sends your commits to GitHub.
git status
git add .
git commit -m "Add signup form labels"
git push

Start a repo and connect it Day 2

Make an empty repo on GitHub first (no README), then copy its URL.

cd ~/Documents/codex
mkdir week-1-checkpoint
cd week-1-checkpoint
git init
# ...make a file, then ACP once...
git remote add origin https://github.com/USER/week-1-checkpoint.git
git push -u origin main

-u is only needed on the first push. After that, plain git push works.

If the repo already exists on GitHub, use git clone URL instead of all of the above.

.gitignore Day 3

A file named exactly .gitignore in the top folder of the repo. Git skips anything that matches a line in it.

# system junk
.DS_Store
Thumbs.db

# editor settings
.vscode/

# secrets, never commit
.env

If a file was already committed, adding it here won't remove it. Run git rm --cached filename, then commit.

Undo, safely

SituationCommand
Throw away edits to a filegit restore file.html
Unstage a file you addedgit restore --staged file.html
Fix the last message (not pushed yet)git commit --amend -m "Better message"

git restore can't be undone. When you're not sure, ask before running it.

Common mix-ups

fatal: not a git repository

You're in the wrong folder. Run pwd, then cd into your project.

A strange editor opened after git commit

You left off -m. Press Esc, type :wq, press Enter.

Push rejected: "fetch first"

GitHub has commits you don't. Run git pull, then git push.

git init in your home folder

Now everything looks "changed". Stop and ask your instructor before deleting anything.
