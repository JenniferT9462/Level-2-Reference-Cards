Week 4

Responsive & Frameworks

Style the phone layout first, then add changes for wider screens. Bootstrap and Tailwind give you ready-made classes for both.

phone → tablet → desktop@media (min-width: 768px)

Mobile-first CSS

Base styles are for phones. Each media query adds changes for screens at least that wide.

.cards {
  display: flex;
  flex-direction: column;   /* phone: stacked */
  gap: 16px;
}

@media (min-width: 768px) {
  .cards { flex-direction: row; }  /* tablet and up */
}

CSS Grid Day 4

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
.feature { grid-column: span 2; }

/* as many columns as fit, each at least 200px */
.auto {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}

1fr means one share of the leftover space.

Flexbox or Grid?

  • Flexbox for one direction: a nav bar, a row of buttons, a card's insides.
  • Grid for rows and columns together: a gallery, a page layout.

You can use both: a grid of cards, with flexbox inside each card.

Bootstrap setup

Put the CSS link in <head>. Open the docs for the same version you linked.

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

Bootstrap grid

Container → row → columns. A row has 12 columns.

<div class="container">
  <div class="row g-3">
    <div class="col-12 col-md-6 col-lg-4">A</div>
    <div class="col-12 col-md-6 col-lg-4">B</div>
    <div class="col-12 col-md-12 col-lg-4">C</div>
  </div>
</div>

Phone: full width. md: halves. lg: thirds.

Test it

  1. Open DevTools (F12) and click the device toolbar icon (Ctrl + Shift + M).
  2. Drag the width from 360px up to 1400px.
  3. Look for sideways scrolling, squished text and overlapping boxes.

Common mix-ups

Thinking md: means "only on tablets"

It means tablet and up. Style phones with no prefix.

Bootstrap columns don't line up

col-* must be direct children of a row, inside a container.

A class from the docs does nothing

The docs version doesn't match the version you linked. Check the version picker.

Media query never applies

Is the viewport meta tag missing? Or is the query above the rule it should override? Order matters.
