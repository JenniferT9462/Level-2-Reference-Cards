Async & fetch

A request takes time and can fail. Your page should show something useful while it waits, when it works, and when it doesn't.

loadingsuccessemptyerror

What a promise is

A promise is a value that isn't ready yet. It ends in one of two states:

  • fulfilled: it worked, and here's the value
  • rejected: it failed, and here's the error

While it waits, it's pending. await pauses your function until it settles.

The basic shape

async function loadPlants() {
  const response = await fetch(url);
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }
  const data = await response.json();
  return data;
}

You can only use await inside an async function.

Why check response.ok?

fetch only rejects when the network fails. A 404 or 500 still counts as "fulfilled", so you have to check the status yourself.

response.oktrue for 200–299
response.statusThe number, like 404
response.json()Reads the body (it's a promise too)

Show every state

async function showPlants() {
  status.textContent = "Loading…";
  button.disabled = true;
  try {
    const data = await loadPlants();
    if (data.length === 0) {
      status.textContent = "No plants found.";
      return;
    }
    render(data);
    status.textContent = "";
  } catch (error) {
    status.textContent = "Couldn't load plants. Try again.";
    console.error(error);
  } finally {
    button.disabled = false;
  }
}

Render the result

function render(plants) {
  list.replaceChildren();
  plants.forEach((p) => {
    const li = document.createElement("li");
    li.textContent = `${p.name}: ${p.days} days`;
    list.append(li);
  });
}

Show only the fields you need. Use textContent for anything that came from an API.

Common mix-ups

You see Promise {<pending>}

You forgot await, so you logged the promise instead of its value.

await is only valid in async functions

Add async before the function that uses await.

A 404 page shows "Success!"

Check response.ok before reading the data.

Blocked by CORS policy

The API doesn't allow browser requests. It works in Postman but needs a proxy for your page (Week 7).
