Variables

const name = "Sam";     // can't be reassigned
let count = 0;          // can change
count = count + 1;

Start with const. Switch to let only when the value has to change. Avoid var.

Objects

const member = {
  name: "Ava",
  plots: 2,
  tools: ["trowel", "gloves"],
};

member.name           // "Ava"
member["plots"]       // 2
member.plots = 3;     // change
member.email = "a@x"; // add
member.tools[0]       // "trowel"

Functions

function greet(name) {
  return `Welcome, ${name}!`;
}

const greet2 = (name) => `Welcome, ${name}!`;

greet("Ava");  // "Welcome, Ava!"

Without return, a function gives back undefined.

this Day 2

Inside a regular method, this is the object before the dot.

const plot = {
  crop: "beans",
  describe() {
    return `Growing ${this.crop}`;
  },
};
plot.describe();  // "Growing beans"

Arrow functions don't get their own this, so don't use them as object methods.

JSON round trip Day 2

JSON is text that looks like an object. APIs and localStorage both use it.

const text = JSON.stringify(member);
// '{"name":"Ava","plots":3,...}'

const back = JSON.parse(text);
back.name  // "Ava"

In JSON, keys need double quotes and trailing commas aren't allowed.

Select elements

const form = document.querySelector("#signup");
const title = document.querySelector("h1");
const cards = document.querySelectorAll(".card");

These use the same selectors as CSS: #id, .class, tag. If nothing matches, querySelector returns null.

Handle a form Day 3

const form = document.querySelector("#signup");
const output = document.querySelector("#result");

form.addEventListener("submit", (event) => {
  event.preventDefault();  // stop the page reload
  const name = form.elements.name.value.trim();
  output.textContent = `Thanks, ${name}!`;
  form.reset();
});

Update the page safely

// text from users or APIs: textContent
el.textContent = userInput;

// build new elements
const li = document.createElement("li");
li.textContent = member.name;
li.classList.add("member");
list.append(li);

// clear a list before re-drawing it
list.replaceChildren();

Don't put user or API text into innerHTML. If it contains HTML tags, the browser runs them.

Debug in the Console

console.log("form value:", name);
console.table(members);   // arrays of objects as a table

Open DevTools with F12. A red error shows the file and line number. Click it to jump there.

Common mix-ups

Cannot read properties of null

Your selector found nothing. Check the spelling, or that the script tag is at the end of <body>.

The page reloads and your result vanishes

Add event.preventDefault() in the submit handler.

"2" + "3" gives "23"

Input values are always strings. Convert with Number() first.

Assignment to constant variable

You reassigned a const. Use let if it really needs to change.
